# handwash-master — Nhận diện thao tác rửa tay

Nhận diện các bước/thao tác rửa tay từ dữ liệu, gồm hai hướng tiếp cận độc lập.

## Cấu trúc
- `BAO's approach/` — hướng của Bảo:
  - `good_ideas/two_stage_hierarchical/` — mô hình phân cấp hai tầng + features `.npy` đã xử lý
  - `models/`, `results/`, `src/`
- `THAI's approach/` — hướng của Thái

## Ghi chú
Features `.npy` đã xử lý được lưu trong repo; có thể tái tạo từ dữ liệu thô bằng script nếu cần.
